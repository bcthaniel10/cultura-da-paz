Fontes & Tipografia do Projeto

Entenda como a fonte Plus Jakarta Sans foi aplicada para transmitir clareza, empatia e acessibilidade em todo o site.

1. Fonte Principal: Plus Jakarta Sans

A família tipográfica escolhida é uma Sans-Serif moderna e altamente legível em telas digitais, perfeita para a transmissão de mensagens claras sobre harmonia e comunidade.

Amostras de Pesos (Weights) Utilizados:

Regular (400): Usado nos parágrafos e textos longos para uma leitura leve e fluida.

Medium (500): Usado no menu de navegação e pequenos detalhes.

Semi-Bold (600): Usado nos botões, subtítulos e destaques de citações.

Bold (700): Usado no título principal (H1) e logomarca para passar presença e estrutura.



2. Códigos de Importação no Projeto

Para utilizar esta fonte no VS Code, basta incluir o código de importação no arquivo HTML ou CSS:

A) Importação via Tag HTML (``)

Coloque esta linha dentro da tag do seu arquivo HTML:

<link href="https://fonts.googleapis.com/css2?family=Plus+Jakarta+Sans:wght@400;500;600;700&display=swap" rel="stylesheet">

B) Regra CSS (`font-family`)

Aplique no arquivo style.css para definir a fonte em todo o documento:

body {
  font-family: 'Plus Jakarta Sans', sans-serif;
}
